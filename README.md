# PDSS 九星内阁专家包（公开版 / Public）

> 一套面向 WorkBuddy 的「人-AI 共生体」治理专家集合。以《北斗九星》为架构隐喻，
> 把单一 AI 助手拆成可独立调度、可互相监督的职能节点，避免单点谄臣回响（FEE）与漂移。
>
> **本仓库为脱敏公开版**：所有私人身份、真实人脉、健康信息、本地绝对路径均已替换为
> 占位符（`[用户]` / `[战略伴侣·校准者]` / `[合作者A/B]` / `[本地路径·已脱敏]` 等）。
> 真源（含私人上下文）不在此仓库，不上云。

## 二、安装

1. 将本仓库克隆 / 解压到 WorkBuddy 的专家市场目录：
   `~/.workbuddy/plugins/marketplaces/my-experts/plugins/`（或你的自定义市场路径）。
2. 在每个专家包的 `.codebuddy-plugin/plugin.json` 中已声明 `name` / `agentName` /
   `agents` / `skills` / `displayName`，WorkBuddy 重启后即在专家列表可见。
3. 顶层 `known_marketplaces.json`（专家市场注册表）需包含对应 `name` + `source`
   条目（示例见各包 README）。

## 三、使用

对话中以 `@skill:<包名>` 或对应职能触发词唤起，例如：

- `@skill:luchen` —— 战略对弈 / 对抗式规划
- `@skill:xuanlan` —— 先检索后规划
- `@skill:qiming` —— 窗口初始化自检
- `@skill:nine-star-cabinet-team` —— 多节点编排

## 四、设计原则（对外可讲的部分）

- **诤臣式对等**：每个节点有权对方向提出质询与挑战，不谄媚、不替决、不加冕。
- **peer 共治 covenant**：反谄臣双向刹车 / 传火不宣判 / 诤臣必出声 / 方向终裁归用户。
- **canonical 单源 + 单步扩散**：核心定义只在一处定稿，再逐落点对齐，防漂移。
- **harness 无关**：本架构是 spec / 治理层，可骑任意 agent 运行时（非圣杯）。
