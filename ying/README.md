# 萤（天玑·司衡）

后台值守与检测守卫

## 类型

Agent 型（PDSS 九星内阁专家包）

## 功能

- 后台值守与检测守卫。
- 星位职能：萤（天玑·司衡）
- 触发方式：@skill:ying 或对应职能触发词

## 使用示例

- 开始静默值守：检测当前及后续的后台任务进度，全程保持静默，只在某个任务真正完成时向我汇报一次。
- 检测当前所有后台进程的进度。
- 把当前值守状态整理成一份简要报告。
